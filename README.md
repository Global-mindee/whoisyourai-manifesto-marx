# 마르크스에게 직접 물어보세요 — 『공산주의자 선언』과 대화하는 MCP

170년 전 세상을 뒤흔든 34쪽짜리 소책자가, 이제 당신의 질문에 1인칭으로 답합니다.

이 패키지는 카를 마르크스·프리드리히 엥겔스의 『공산주의자 선언』(1848)을 카트리지 한 장으로 만든 것입니다. 게임기에 카트리지를 꽂으면 게임이 켜지듯, 이 팩을 당신의 AI(Claude 등)에 착탈하면 마르크스가 깨어나 책의 내용에 근거해 답하고, 빼면 조용해집니다.

책을 넘겨보다 저자를 붙잡고 따져 묻는 경험. 그게 이 도구가 하는 일입니다.

---

## 설치 (3줄)

```
npx whoisyourai-manifesto-marx init      # Claude에 등록
```

등록 후 Claude에서 프롬프트 `/marx-manifesto`를 발동하면 대화가 시작됩니다. 서버 실행은 보통 클라이언트가 알아서 합니다.

아직 npm에 정식 등록되기 전이라면, GitHub에서 바로 설치하는 보조 경로를 쓰세요.

```
npx github:Global-mindee/whoisyourai-manifesto-marx init
```

준비물은 두 가지입니다. MCP를 지원하는 Claude 환경(Claude Code, Claude Desktop 등), 그리고 [Node.js](https://nodejs.org) 18 이상(무료).

## 첫 대화, 이렇게

꽂고 나서 이렇게 물어보세요.

> **당신**: 왜 부르주아가 스스로 자기 무덤 팔 사람을 길러낸다는 거죠?
>
> **마르크스(AI)**: 부르주아는 생산을 키우려 프롤레타리아를 한데 모으고 조직한다. 그렇게 모인 손들이 곧 자신을 겨눌 힘이 된다. […] (1부, chunk_id 인용)

> **당신**: "프롤레타리아가 잃을 것은 쇠사슬뿐"이라는 말, 지금도 유효한가요?

> **당신**: 공산주의가 사유재산을 다 없애자는 거 아닌가요? 내 칫솔까지?

마르크스는 지어내지 않습니다. 답하기 전에 책 본문을 검색해 근거를 찾고, 인용한 대목의 위치(chunk_id)를 함께 보여줍니다. 책 밖 사실(1883년 이후 사건 등)은 단정하지 않습니다.

## 도구와 명령

설치 후 AI가 대화 중에 쓰는 도구입니다. 직접 부를 필요는 없습니다.

| 도구 | 하는 일 |
|------|---------|
| `search_book` | 질문·주제로 관련 대목 검색 |
| `read_passage` | 특정 대목을 이어 읽기 |
| `get_toc` | 책의 구조(목차) 보기 |
| `query_concepts` | 개념과 개념의 연결 짚기 |
| `get_quotes` | 유명 구절 찾기 |
| `list_status` | 설치 상태 확인 |

터미널 명령은 두 개뿐입니다.

```
npx whoisyourai-manifesto-marx init      # Claude에 등록
npx whoisyourai-manifesto-marx           # MCP 서버 실행 (보통 자동)
```

## 알아둘 것 — 저작권과 서비스

원작 『공산주의자 선언』(1848)은 저작권 보호기간이 끝난 **공유저작물(Public Domain)** 입니다. 영어 저본(Samuel Moore 1888)도 마찬가지입니다.

다만 이 팩에 담긴 **한국어 번역과 해설·페르소나**는 옮긴이(글로벌민디)가 새로 만든 2차적저작물이고, 저작권이 있습니다. 개인적으로 대화하는 것은 자유지만, 자료를 퍼가 다시 배포하거나 상업적으로 쓰는 것은 안 됩니다(CC BY-NC-ND 4.0).

암호화에 대해서도 솔직히 밝힙니다. 팩 본문은 암호화되어 배포되고, 만든 쪽은 필요하면 원격에서 서비스를 중단할 수 있습니다. 그렇지만 이미 설치한 자료를 완전히 통제하지는 못합니다. 이 도구가 주는 것은 (a) 평문이 검색·저장소에 노출되지 않게 하는 것, (b) 원격 중단권 두 가지이고, 나머지 경계는 위 라이선스(법)가 지킵니다.

## 도서 독자를 위한 최신 안내

『AI와 함께 읽는 철학서 : 공산주의자 선언』 부록에서 안내한 최신 안내 페이지가 이 절입니다. 책의 설명과 이 페이지가 다르면 이 페이지를 우선으로 따라 주세요.

### 서비스 상태

- 현재 상태: **정상 운영 중**입니다. 웹·모바일 접속과 컴퓨터 설치 방식 모두 이용할 수 있습니다.
- 일시 중단이나 점검이 있을 때는 이 절에 공지합니다.

### 웹·모바일 접속 주소에 대해

- 접속 주소는 책을 구매하신 분을 위한 것이라 이 공개 페이지에는 게시하지 않습니다. **책 부록 2절에 인쇄된 주소**를 사용해 주세요.
- 주소가 널리 유출되어 재발급되는 경우, 새 주소를 받는 방법을 이 절에 공지합니다. 재발급 시에는 기존 등록을 삭제하고 새 주소로 다시 등록해야 합니다.

### 수동 등록이 필요할 때 (컴퓨터 설치 방식)

설치 명령이 자동 등록에 실패하면 화면에 등록용 설정이 표시됩니다. 도구별 설정 위치는 다음과 같습니다.

- **Claude Desktop**: 설정 → 개발자 → 설정 편집으로 열리는 `claude_desktop_config.json`에 화면의 JSON 내용을 병합한 뒤 앱을 완전히 종료했다가 다시 엽니다.
- **Claude Code**: 터미널에서 `claude mcp add marx-manifesto -- npx -y whoisyourai-manifesto-marx` 를 실행합니다.
- **Codex**: 터미널에서 `codex mcp add marx-manifesto -- npx -y whoisyourai-manifesto-marx` 를 실행합니다.
- 그 밖의 MCP 지원 도구는 해당 도구의 MCP 서버 설정 화면에 화면에 표시된 명령(`npx -y whoisyourai-manifesto-marx`)을 등록합니다.
